# 英文查询关联数据要求

已有 XLSX 中的查询表为全站独立维度，只有 1,000 行、合计 45 次点击，没有查询对应页面的列。不得与网页表按行号或相似词硬连接。匿名查询与导出截断会造成不完整覆盖。

需要的核心字段为 date、query、page、clicks、impressions、position。仅保留实际英文 URL；若另取 country、device，记录其维度与筛选，保持前后可比，不能无条件横向合并聚合结果。

可由有权限的人在 GSC 先限定英文 URL 范围，再筛选某个查询并查看网页分布；对高优先查询查看日期变化。大批量分析可使用 Search Console API 或已有批量导出权限，不假设当前已接入。

先分析法兰与车铣零件候选组，再检查材料文章/服务页的购买与知识查询归属。需要前一可比期间时另行导出；原文件没有前期数据，不计算虚构环比。

统计“同查询竞争”时以不同基础页面为单位，目录锚点归属原文档；同时保留原始链接记录，避免丢失 Google 展示形式信息。多个不同用途结果获得点击并不自动需要合并。
